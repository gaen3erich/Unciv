# LLM-агент в обычной игре с интерфейсом

Агент играет одной (или несколькими) AI-цивилизациями в обычной партии Unciv, а вы смотрите за ним
в окне игры, например как Spectator. Всё остальное в партии работает как обычно.

## Как это устроено

- Desktop-лаунчер читает `--llm-config=...` (или переменную `UNCIV_LLM_CONFIG`). Без неё игра ведёт себя как обычно.
- Когда в обычном цикле ходов доходит очередь до контролируемой AI-цивилизации, вместо встроенного ИИ
  вызывается LLM: до `--llm-max-calls` запросов за ход (по умолчанию 3), пока модель не выберет `end_turn`.
- Решает модель: исследования, производство в городах, юниты (группами: found / attack / defend / run_units),
  война и мир. Остальное делает встроенный ИИ: ответы на попапы и торговые предложения, социальные институты,
  религия, шпионы, обстрел из городов, голосования. Если модель не выбрала технологию или очередь города
  пуста, их заполняет встроенный ИИ.
- Если запрос к модели упал с исключением, этот ход играет встроенный ИИ (видно в консоли).
- Если модель назвала недоступное действие или ответ не разобрался, её один раз переспрашивают с указанием ошибки
  (до применения чего-либо, поэтому реальных запросов за ход может быть вдвое больше `--llm-max-calls`). Если и второй
  ответ содержит недоступные действия, они отбрасываются, а остальные применяются.
- Каждое решение печатается в консоль (`[LLM Rome T12 #1] tech:Writing, build:Rome:Monument, run_units, end_turn ...`,
  плюс `why:` и `notes:` модели) и пишется в JSONL-трейс.

## 1. Что нужно на машине

- JDK 21 (`java -version`), git.
- Репозиторий на ветке `codex-api-observation-llm`:

```bash
git clone https://github.com/gaen3erich/Unciv.git
cd Unciv
git checkout codex-api-observation-llm
```

## 2. Туннель к DeepSeek

Сервер с моделью должен отдавать OpenAI-совместимый API (`/v1/chat/completions`): vLLM, SGLang, Ollama,
llama.cpp server и т.п. Пробросьте его порт на свою машину. Пример: на удалённой машине vLLM слушает 8000.

```bash
ssh -N -L 8000:localhost:8000 user@gpu-host
```

(для Ollama обычно порт 11434: `ssh -N -L 11434:localhost:11434 user@gpu-host`).

Проверьте в другом терминале, что модель видна, и запомните её имя (`id`):

```bash
curl http://localhost:8000/v1/models
```

## 3. Конфиг агента

Возьмите `configs/llm-agent/deepseek-ssh.json` и поправьте:

- `model`: точное имя из `/v1/models` (например `deepseek-ai/DeepSeek-V3` или `deepseek-r1:32b` в Ollama);
- `baseUrl`: `http://localhost:8000/v1` (для Ollama `http://localhost:11434/v1`);
- `useTools`: `true` шлёт OpenAI tool calling с принудительным `pick_actions`. Если сервер отвечает 400
  на `tools`/`tool_choice` или модель их не умеет (DeepSeek-R1 и дистилляты), поставьте `false`: тогда
  модель просят ответить одним JSON-объектом в тексте, а блок `<think>...</think>` отбрасывается при разборе;
- ключ не нужен; если сервер его требует, добавьте `"apiKeyEnv": "DEEPSEEK_API_KEY"` и задайте эту переменную;
- `timeoutSeconds`: для reasoning-моделей лучше 300 и больше.

## 4. Запуск игры

Linux / macOS:

```bash
./gradlew desktop:run --args="--llm-config=configs/llm-agent/deepseek-ssh.json --llm-civ=Rome"
```

Windows (PowerShell):

```powershell
.\gradlew.bat desktop:run --args="--llm-config=configs/llm-agent/deepseek-ssh.json --llm-civ=Rome"
```

Вместо аргументов можно задать переменные окружения `UNCIV_LLM_CONFIG`, `UNCIV_LLM_CIV`,
`UNCIV_LLM_MAX_CALLS`, `UNCIV_LLM_TRACE`. Аргументы:

| аргумент | по умолчанию | что делает |
|---|---|---|
| `--llm-config=<путь>` | нет | конфиг агента; относительный путь ищется от корня репозитория |
| `--llm-civ=Rome,Greece` | первая AI-цивилизация партии | какие цивилизации играет агент (английские имена из правил) |
| `--llm-max-calls=3` | 3 | сколько раз за ход можно спросить модель, если она не выбрала `end_turn` |
| `--llm-trace=<путь>` | `~/unciv-llm/ingame-<время>.jsonl` | трейс всех решений |

В консоли сразу после старта должна появиться строка вида
`llm: agent 'deepseek-ssh' (openai-compat:...) plays Rome, up to 3 calls per turn, trace ...`.
Если конфиг не найден или некорректен, игра завершится с сообщением `llm: cannot start the in-game agent: ...`.

## 5. Партия

1. New game. Маленькая карта (Tiny/Small) и 2–4 цивилизации, чтобы ходы шли быстро.
2. В списке игроков поменяйте себя на **Spectator** (или оставьте себя человеком, если хотите играть против агента).
3. Добавьте AI-игрока **Rome** (или ту цивилизацию, что указали в `--llm-civ`).
4. Start game и жмите Next turn. Пока модель думает, игра показывает обычный прогресс хода.
   Чтобы ходы шли сами: Options → Automation → раздел AutoPlay, включите «Show AutoPlay button» и задайте
   число ходов; рядом с Next turn появится кнопка AutoPlay.

Агент работает и в загруженных сохранениях: нужная цивилизация должна быть AI.
Онлайн-мультиплеер не поддерживается.

## Если что-то не так

- `FALLBACK: client_error` в консоли: сервер недоступен (туннель упал, неверный порт или имя модели). Проверьте `curl`.
- `FALLBACK: parse_failure`: модель ответила не тем форматом. Попробуйте `useTools: false`/`true`,
  увеличьте `maxTokens` (reasoning-модели тратят много токенов на `<think>`), посмотрите ответ в трейсе.
- Юниты стоят на месте: модель не выбрала `run_units`. Видно в строке решений; подсказка про это есть в системном промпте.
- Полный промпт и ответ каждого шага лежат в трейсе, если в конфиге `"trace": {"includePrompts": true}`.
